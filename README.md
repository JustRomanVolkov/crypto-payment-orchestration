# Crypto Payment Orchestration

Architecture and technical design of a cryptocurrency payment
orchestration system.

The documentation covers payment lifecycle management, provider
routing and cascading, idempotency, webhook processing,
reconciliation, failure recovery, and reliable event delivery.

It explores domain-driven design, application use cases,
API and persistence contracts, transactional consistency,
and integration with other business services.

Architectural decisions cover both modular monolith and
microservice approaches, including service boundaries,
infrastructure choices, scalability, and trade-offs.

Start with the [Billing documentation](docs/billing/README.md) for the main overview and navigation.

Documentation is written in Russian.
